## 2. 采样时钟实验（P6-C）——明确的负面结论

- 因果构造：3 币种 × 3 种采样 × 8 个增长前缀 → **0 个历史 bar 被改写**；流式与批量在边界/OHLC 精确一致（volume 相对差 ≤1.7e-15，求和顺序）
- 按原样（含跨空洞收益）**无受支持的分布改善**：Δexkurt 的 bootstrap 区间处处跨 0；根因是 1m 缓存的空洞（当前 **27 个 / 166 499 缺失分钟 / 23.86 %**，最大 61.8 天），时间棒跨越空洞会把未成交跳空计入价格
- 同时剔除跨空洞收益后 Δexkurt **12/12 为负**（4000 根处 6/6 bootstrap 支持）——**这是本缓存空洞的性质，不是改用时钟的理由**
- 决定性检验（同一协议、同一 v2 契约、成本 0.25 %）：时间棒 AUC **0.5361**、净 −0.3276 %、1790 笔、t −7.600 → FAIL；美元棒 AUC **0.4664–0.4748**、净 −0.3335…−0.4254 % → FAIL；**ΔAUC −0.0697/−0.0613**，**Δnet −0.0059…−0.0978 pp**。早期轮次曾写"净成本后略好 +0.0103 pp"，**该结论已被判定为错误并改正**：美元棒在 AUC 与净收益上**都更差**
- 数字随缓存修订漂移（美元棒 AUC 一路 0.5079→0.5014→0.4823→0.4679→0.4748），**两次拒绝稳定**
